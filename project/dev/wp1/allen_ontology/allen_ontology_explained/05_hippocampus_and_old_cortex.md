# 05 · Hippocampus and the "old" cortex

These are the two non-neocortical parts of `Cx`.

## ACx · allocortex: the oldest cortex (3 layers)

```
ACx allocortex
├── ArCx  archicortex
│   ├── HIP  hippocampus (hippocampal formation)   (121 structures)
│   ├── IG   indusium griseum     (thin grey layer on top of the corpus callosum)
│   └── TT   taenia tecta
└── PalCx paleocortex: the olfactory cortex
    ├── OB  olfactory bulb    ├── OT  olfactory tubercle    ├── Pir  piriform cortex
    ├── AON anterior olfactory nucleus   ├── LOA, NLOT, PEA (small olfactory areas)
```

| Structure | Function |
|---|---|
| **Hippocampus** | forming new memories of events and facts; spatial navigation ("place cells") |
| **Olfactory bulb and piriform cortex** | smell: the bulb receives the nose's input and the piriform cortex identifies odours |
| **Olfactory tubercle** | links smell with reward and motivation |

## Inside the hippocampus: three cuts at once

```
HIP
├── DG    dentate gyrus      → uncal / rostral / caudal  → molecular, granular, subgranular, polymorph layers
├── Hipp  hippocampus proper → CA1, CA2, CA3, CA4        → uncal / rostral / caudal → strata (layers)
└── Sub   subicular cortex   → subiculum, prosubiculum, supracallosal subiculum
```

The hippocampus is cut three ways, one after the other:

1. **Field:** DG, CA1–CA4 or subiculum.
2. **Position along the long axis:** *uncal* (the front hook), *rostral* (head) or *caudal*
   (body/tail).
3. **Layer:** e.g. `stratum pyramidale` (the cell bodies), `stratum radiatum`, `stratum oriens`,
   `stratum lacunosum-moleculare`.

So `CA1Rsp` = **CA1**, **R**ostral, **s**tratum **p**yramidale.

Simplified roles of the fields:
- **DG:** separates similar memories ("pattern separation"); new neurons are born here in the
  subgranular zone.
- **CA3:** completes a memory from a partial cue.
- **CA1:** compares memories with what is happening now, and is the main output.
- **Subiculum:** sends the hippocampus' output to the rest of the brain.

## PACx · periallocortex: the transition belt

This belt sits between the old allocortex and the neocortex:

```
PACx periallocortex
├── PArCx periarchicortex (next to the hippocampus)
│   ├── EC   entorhinal cortex    ├── A35 perirhinal cortex   ├── PrS presubiculum
│   ├── PaS  parasubiculum        └── RSC retrosplenial cortex
└── PPCx  peripaleocortex (next to the olfactory cortex): agranular insula Iag, FI, TI
```

| Structure | Function |
|---|---|
| **Entorhinal cortex** | the gateway to the hippocampus; maps space ("grid cells"); one of the first areas affected in Alzheimer's disease |
| **Perirhinal cortex (A35)** | recognising objects as familiar |
| **Presubiculum and parasubiculum** | sense of head direction |
| **Retrosplenial cortex** | navigation, imagining scenes, recalling the past |
| **Agranular insula** | autonomic and emotional responses, taste and smell integration |
