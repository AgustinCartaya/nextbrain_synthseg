# 07 · Diencephalon (Die)

```
Die diencephalon (190)
├── THM    thalamus      (115)
├── HTH    hypothalamus  ( 67)
├── SubTH  subthalamus   (STH subthalamic nucleus)
└── Ret    retina
```

## Thalamus: the relay station to the cortex

Almost all information that reaches the cortex, except smell, passes through the thalamus first.
Allen groups the thalamic nuclei by **position**:

```
THM thalamus
├── DTH  dorsal thalamus (the "real" thalamus)
│   ├── ANC  anterior complex      (AD, AM, AV, LD)
│   ├── MNC  medial complex        (MD mediodorsal, Re reuniens, Pt)
│   ├── LNC  lateral complex
│   │   ├── DLN dorsal group:  LP, Pul pulvinar
│   │   └── VLN ventral group: VA, VL, VPT (VPL / VPM), VM
│   ├── PoN  posterior complex     (LG lateral geniculate, MG medial geniculate, Po, LSG)
│   ├── ILN  intralaminar complex  (centromedian, parafascicular, central lateral, ...)
│   └── MiN  midline complex
├── ETH  epithalamus     (habenula, paraventricular nucleus, Pin pineal body)
├── VTH  ventral thalamus (ZI zona incerta, field of Forel, ...)
└── R    reticular nucleus
```

| Nucleus / group | Function |
|---|---|
| **Anterior (AD, AM, AV)** | memory circuit (Papez circuit), with the hippocampus and the mammillary bodies |
| **Mediodorsal (MD)** | prefrontal cortex partner: working memory, decisions, emotion |
| **VA / VL** | motor relay from the basal ganglia and cerebellum to the motor cortex |
| **VPL / VPM** (in VPT) | touch, pain and temperature from the body (VPL) and the face (VPM) to S1 |
| **LGN** (lateral geniculate) | vision: from the retina to V1 |
| **MGN** (medial geniculate) | hearing: to the auditory cortex |
| **Pulvinar** | visual attention, linking visual areas |
| **Intralaminar / midline** | arousal, wakefulness, attention |
| **Reticular nucleus** | a shell around the thalamus that gates the flow of information; sleep spindles |
| **Habenula** (epithalamus) | "anti-reward": signals disappointment and controls dopamine and serotonin; involved in depression |
| **Pineal body** | melatonin and the day–night rhythm |
| **Zona incerta** | integrating movement, attention and the body's internal state |

## Hypothalamus: the body's control centre

The hypothalamus is grouped from **front to back** in four regions, plus the pituitary:

| Region | Main nuclei | Function |
|---|---|---|
| `HTHpo` preoptic | MPN, MnPO, LPA | body temperature, thirst, sleep, sexual behaviour |
| `HTHso` supraoptic (anterior) | **SCN**, **PV**, **SO**, AHN | **SCN** = the master biological clock (circadian rhythm); PV and SO make oxytocin and vasopressin and drive the stress response |
| `HTHtub` tuberal (middle) | **Arc**, VMH, DMH, LHA | hunger and satiety (arcuate, VMH), lateral hypothalamus = feeding and wakefulness (orexin) |
| `HTHma` mammillary (back) | **MN** mammillary nucleus, TM, PHN | memory (Papez circuit), arousal (histamine from TM) |
| `Pit` pituitary | | hormone gland controlled by the hypothalamus |

## Subthalamus

**STH (subthalamic nucleus)** is part of the basal-ganglia circuit and acts as a brake on movement.
It is the most common target of deep brain stimulation for Parkinson's disease.
