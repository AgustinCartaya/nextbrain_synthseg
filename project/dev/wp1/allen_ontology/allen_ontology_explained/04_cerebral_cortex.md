# 04 · The neocortex (NCx)

The neocortex is organised in three steps: **lobe → area → (sub-area) → layer**.

```
NCx neocortex
├── FCx  frontal neocortex     (250)
│   ├── PFC   prefrontal cortex         (A10 frontal pole, DFC dorsolateral, VFC ventrolateral = A44/A45)
│   ├── OFC   orbital frontal cortex
│   └── PoFC  posterior frontal = motor cortex (M1C area 4, PMC premotor area 6)
├── PCx  parietal neocortex    (152)
│   ├── S1C   primary somatosensory cortex (areas 3, 1, 2)
│   └── PoPC  posterior parietal cortex
├── TCx  temporal neocortex    (191)   (DLTC with A1C primary auditory, VLTC, A38 temporal pole, V5/MT, ...)
├── Ocx  occipital neocortex   ( 85)   (V1C primary visual, ESOC extrastriate)
├── ICx  insular neocortex     ( 30)
└── CCx  cingulate neocortex   ( 51)   (anterior MFC, mid MCC, posterior PCC)
```

## What each lobe does

| Lobe | Key areas in the tree | Function |
|---|---|---|
| **Frontal** `FCx` | `PFC` (A9, A46, A10), `OFC`, `PoFC` (motor) | planning, decision making, working memory, self-control and personality (PFC); reward value and social behaviour (OFC); voluntary movement (motor cortex); speech production (Broca's area = `A44` + `A45`, under `VFC`) |
| **Parietal** `PCx` | `S1C`, `PoPC` | touch, pain, temperature and body position (S1); spatial attention, combining the senses, reaching and grasping (posterior parietal) |
| **Temporal** `TCx` | `DLTC` (`A1C` primary auditory, `A42`, area 22), `VLTC`, `A38` pole, `V5/MT` | hearing and language comprehension (Wernicke, superior temporal); recognising objects and faces (ventral temporal); semantic memory (pole); visual motion (V5/MT) |
| **Occipital** `Ocx` | `V1C` (area 17), `ESOC` (V2, V3, ...) | vision: V1 receives the eyes' input, extrastriate areas analyse shape, colour and motion |
| **Insular** `ICx` | `Idg`, `Ig` | feeling the body from inside (heartbeat, hunger), taste, disgust, emotional awareness |
| **Cingulate** `CCx` | `MFC` anterior, `MCC` mid, `PCC` posterior | detecting conflict and errors, motivation and pain affect (anterior); action selection (mid); self-reflection and the default-mode network (posterior) |

## Areas and Brodmann numbers

Many leaf names are **Brodmann areas**: `A8`, `A9`, `A46`, `A10`, `A37`, `A38`, area 17 (V1), and so
on. Each Brodmann area is a patch of cortex with a distinct cell structure. Allen often splits them
further, e.g. `A46` → `A46d` dorsal and `A46v` ventral.

## Layers: the deepest level

The neocortex has **6 layers**, numbered I (surface) to VI (next to the white matter). Allen lists
them as the leaves of many areas:

```
V1C primary visual cortex
├── V1-1 layer I     ├── V1-4 layer IV  (IVA, IVB, IVC → V1-4C: the eye input arrives here)
├── V1-2 layer II    ├── V1-5 layer V
└── V1-3 layer III   └── V1-6 layer VI
```

Simplified roles of the layers:
- **IV** receives input from the thalamus.
- **II–III** connect cortical areas with each other.
- **V–VI** send output to subcortical structures (V) and back to the thalamus (VI).

The leaves at depth 12–14 are mostly these layers. That is why the tree is so deep.
