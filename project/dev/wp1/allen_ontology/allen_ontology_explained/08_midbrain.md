# 08 · Midbrain (M)

The midbrain grey matter (`MGM`) is divided **from back (dorsal) to front (ventral)**:

```
M midbrain (212)
├── MGM grey matter (151)
│   ├── MTc  tectum ("roof", at the back)      SC superior colliculus, IC inferior colliculus, ...
│   ├── PTR  pretectal region                  PTN pretectal nuclei, AOP accessory optic nuclei
│   ├── MTg  tegmentum ("floor", at the front)  (98)
│   │   ├── MEN  efferent cranial-nerve nuclei  (III oculomotor, IV trochlear, Edinger-Westphal)
│   │   ├── MAN  afferent cranial-nerve nuclei  (mesencephalic trigeminal)
│   │   ├── PAG  periaqueductal grey
│   │   ├── MRa  raphe nuclei     (DR dorsal raphe, Lin linear, MnR median raphe, ...)
│   │   ├── MRF  reticular formation
│   │   ├── RN   red nucleus
│   │   ├── SN   substantia nigra  (SNC compact, SNR reticular, SNL lateral)
│   │   ├── VTR  ventral tegmental region (VTA)
│   │   ├── IP   interpeduncular nucleus
│   │   └── XMTg other nuclei
│   └── MTS  transient (fetal) structures
├── MWM white matter (46)   cerebral peduncle, superior cerebellar peduncle, lemnisci, ...
├── MV  ventricle           Aq cerebral aqueduct
└── MSS surface             roots of nerves III and IV, interpeduncular fossa, ...
```

## Functions

| Structure | Function |
|---|---|
| **Superior colliculus** | turning the eyes and head toward something you see (fast orienting reflex) |
| **Inferior colliculus** | auditory relay: locating where sounds come from |
| **Pretectal nuclei** | pupil light reflex |
| **Oculomotor (III) and trochlear (IV) nuclei** | eye movements; Edinger-Westphal = pupil constriction |
| **Substantia nigra, compact part (SNC)** | makes **dopamine** for the striatum: starting and learning movements; dies in **Parkinson's disease** |
| **Substantia nigra, reticular part (SNR)** | basal-ganglia output; controls eye movements (saccades) |
| **VTA** (ventral tegmental area) | dopamine for reward, motivation and learning (accumbens, prefrontal cortex) |
| **Red nucleus** | motor coordination, linked with the cerebellum |
| **Periaqueductal grey (PAG)** | pain suppression, defensive behaviour (fight, flight, freeze), vocalisation |
| **Dorsal and median raphe** | the main source of **serotonin**: mood, sleep, impulse control |
| **Reticular formation** | arousal and wakefulness, posture |
| **Interpeduncular nucleus** | receives the habenula's output; aversion, nicotine dependence |

## Midbrain white matter (MWM), in short

- **Cerebral peduncle** (`cpd`): the big descending motor bundle from the cortex.
- **Superior cerebellar peduncle** (`scp`): the cerebellum's output to the red nucleus and thalamus.
- **Lemnisci** (`ml-m`, `ll-m`): the ascending sensory pathways.

The tracts that cross over (e.g. `x4` trochlear decussation, `xscp`) are listed as separate nodes.
